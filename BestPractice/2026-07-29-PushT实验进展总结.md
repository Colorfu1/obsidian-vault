# 2026-07-29 PushT 实验进展总结

## 重要进展

- BCChunk 与 Diffusion 均完成 200,000 updates 的受控训练；闭环选模确定
  BCChunk-150k 和 Diffusion-175k。
- E0 证明训练数据具有丰富的全局轨迹形态，但不证明固定 observation 下存在多个
  action mode。
- E1 表明主要 action 差异来自完整 DDPM reverse sampling stream，而不是 initial
  noise；固定 observation 的 action-mode 分析仍为 0/10。
- E2 完成 220 条主实验闭环 rollout；完整 sampling 能产生多个成功轨迹簇，但
  any@10 是 oracle coverage，不能替代单次部署成功率。
- E3 表明 DDIM-5 是当前 checkpoint 的最佳部署点：success 仅比 DDPM-100 低
  2 个百分点，p95 action-chunk latency 加速 12.57 倍。
- E4 的未适配 OOD rollout 全部失败；接触点变化会改变任务重合度，但没有自然诱导
  出相反接近方向。

## 核心实验问题

整个实验链路不是简单比较两个 success 数字，而是依次回答：

1. demonstration 中是否存在多种完整轨迹形态；
2. 固定 observation 下 Diffusion sampling 是否会改变 action chunk；
3. 这些动作差异能否在闭环反馈中形成不同且成功的完整轨迹；
4. 减少 denoising steps 后，能否保留 success 并降低推理延迟；
5. 原模型的行为偏好能否直接迁移到专门构造的新几何场景。

算法背景可结合
[[Robot/VLA/Diffusion Policy 概述|Diffusion Policy 概述]]阅读；BCChunk 与 ACT
类 action chunking 的关系可对照
[[Robot/VLA/ACT-补充理解-从Action-Chunking到闭环稳定性|ACT：从 Action Chunking 到闭环稳定性]]。

## 受控设置

| 字段 | 设置 |
|---|---|
| Task | PushT |
| Dataset | 206 episodes；165 train / 20 development / 21 held-out audit |
| Observation | 96×96 RGB + 2D agent position，2 帧 history |
| Action | 2D absolute target position |
| Horizon | 内部 16 步；每次执行 `[1:9]` 共 8 步 |
| Control frequency | 10 Hz |
| Train seed | 1000 |
| BCChunk objective | clean-action MSE |
| Diffusion objective | epsilon-prediction MSE |

两个模型使用相同数据、预处理、视觉编码器、temporal U-Net 容量、optimizer、
scheduler 和成对 step-zero 初始化。主要差异只有动作预测目标：

- BCChunk 一次前向直接回归 clean action chunk；
- Diffusion 从 noise 出发，通过多步反向过程生成 action chunk。

因此两种 train loss 的绝对值没有直接可比性。

## 正式训练与 Checkpoint Selection

两个模型都完成 200,000 updates：

| 模型 | 最后记录的 loss | 含义 |
|---|---:|---|
| BCChunk | 0.000 | 三位小数的 clean-action MSE，不是精确零 |
| Diffusion | 0.004 | epsilon-prediction MSE |

20 个 development environment seed 的闭环选模结果：

| 模型 | 选中 step | Success | Offline denormalized MSE |
|---|---:|---:|---:|
| BCChunk | 150k | 11/20，55% | 582.31 |
| Diffusion | 175k | 16/20，80% | 1169.87 |

最低 offline MSE、最后 checkpoint 和最高 closed-loop success 并不重合。这是
checkpoint selection 必须使用闭环指标的直接证据。

逐 seed 对照中：

- 仅 BCChunk 成功：1；
- 仅 Diffusion 成功：6；
- 两者都成功：10；
- 两者都失败：3。

Diffusion 在 development 上高 25 个百分点，但 McNemar `p=0.125`，而且这 20 个
seed 已用于选模。因此只能说方向对 Diffusion 有利，不能将 80% 对 55% 写成独立
泛化优势。

## E0：数据多样性不等于条件多模态

E0 审计了 206 条 demonstration 和 25,650 帧：

| 指标 | 结果 |
|---|---:|
| 自动分类的全局策略组 | 33 |
| Block geometry coverage | 100% |
| Mean episode max reward | 0.8923 |
| 显式正 success label | 0 |

33 个全局策略组说明完整轨迹具有多样性，但这些 episode 的初始状态和历史不同。
所以不能从全局聚类推出固定 observation 下

$$
p(a\mid o)
$$

是多峰分布。E0 是 dataset action diversity baseline，不是严格条件多模态证据。

## E1：随机性主要来自完整 Reverse Sampling

E1 固定两帧 observation，使用 10 个 held-out candidate，每个协议生成 20 个
action chunk：

| 指标 | Initial noise only | Full sampling seed |
|---|---:|---:|
| Trajectory pairwise RMS | 0.00659 px | 1.94563 px |
| Endpoint pairwise distance | 0.00750 px | 2.80300 px |
| 通过 action-mode 判据 | 0/10 | 0/10 |

完整 sampling stream 的 trajectory RMS 是 initial-noise-only 的约 295 倍，
endpoint distance 约为 374 倍。因此主要 action 差异来自 reverse sampling
过程，不是 initial noise 本身。

但是 GMM/BIC 与完整 chunk 距离的交叉分析没有找到稳定 action mode。E1 支持
“Diffusion sampling 会产生不同 action pattern”，不支持“固定 observation 的动作
分布已被证明多峰”。

## E2：闭环中出现多个成功轨迹簇

### Initial-noise sensitivity

2 个环境 × 5 个 sampling seed：

- success：5/10；
- first-replan chunk diversity：`4.17e-5`；
- 至少两个 distinct successful mode 的环境：0/2。

极小动作差异可能被闭环动力学放大，但这一协议没有形成多个成功 mode 的证据。

### Full DDPM sampling

20 个环境 × 10 个 Diffusion sampling seed，并在相同环境执行一条 BCChunk：

| 指标 | 结果 |
|---|---:|
| BCChunk success | 5/20，25% |
| Diffusion 单次估计（seed 0） | 11/20，55% |
| 全部 Diffusion samples | 105/200，52.5% |
| Any@10 | 18/20，90% |
| 至少两个成功轨迹簇的环境 | 16/20 |
| Mean / max successful mode count | 3.9 / 8 |
| 成功/失败轨迹 diversity | 0.11576 / 0.18217 |

16/20 个环境存在至少两个按 complete-linkage 轨迹距离定义的成功簇，说明完整 DDPM
sampling 可以产生多个成功闭环行为 mode。

但这里有三个重要边界：

1. 轨迹簇是操作性距离定义，不等于左推/右推等语义策略；
2. any@10 是尝试十次后的 oracle coverage，不是单次部署 success；
3. E2 的闭环分叉不能反向证明 E1 固定 observation 的 $p(a\mid o)$ 多峰。

失败轨迹 diversity 高于成功轨迹，也说明 diversity 本身不是优化目标；无约束的
随机变化更可能扩大失败空间。

## E3：DDIM-5 是当前部署点

E3 对 6 个条件各执行 50 条 rollout，共 300 条：

| 条件 | Success | p95 chunk latency | 相对 DDPM-100 |
|---|---:|---:|---:|
| DDIM-5 | 58% | 47.73 ms | 12.57× |
| DDIM-10 | 56% | 71.86 ms | 8.35× |
| DDIM-20 | 58% | 121.41 ms | 4.94× |
| DDIM-50 | 54% | 307.67 ms | 1.95× |
| DDIM-100 | 58% | 601.05 ms | 1.00× |
| DDPM-100 | 60% | 600.15 ms | reference |

预先定义的合格线是：

- p95 latency 至少加速 2 倍；
- success drop 不超过 5 个百分点。

DDIM-5、10、20 均达标，DDIM-5 延迟最低。它相对 DDPM-100 只损失 2 个百分点，
却加速 12.57 倍，因此是当前 checkpoint 和评测协议下的首选部署配置。

## E4：OOD 场景只能诊断，不能代替训练

E4 没有采集新训练数据，而是把原 PushT Diffusion-175k 直接放进新场景。

同中心纯旋转场景运行 5 条，结果 0/5；mean/best max reward 为 0.5284/0.5858。

在左下角到中心的 180° 场景中，改变初始接触点：

| 接触点 | Success | Mean max reward | Best max reward |
|---|---:|---:|---:|
| left-up | 0/5 | 0.1595 | 0.1648 |
| center | 0/5 | 0.2266 | 0.4110 |
| right-down | 0/5 | 0.5664 | 0.8441 |

右下接触点显著改善重合度，但没有达到 success，也没有诱导出相反接近方向。这个
结果支持“模型行为受训练分布偏好与接触几何共同影响”，不支持“新场景不可学习”。
要验证顺时针/逆时针或左/右策略，仍需相同初始状态的配对 demonstration 和重新训练。

## 结论边界

当前可以说：

1. closed-loop checkpoint selection 不可由 train loss 或 offline MSE 替代；
2. 完整 DDPM reverse sampling 是 action 与闭环行为差异的主要随机来源；
3. Diffusion 在多个相同初始环境中产生了多个成功轨迹簇；
4. DDIM-5 是当前 success-latency Pareto 上的最佳部署配置。

当前不能说：

1. Diffusion 在独立 final set 上显著优于 BCChunk；
2. 固定 observation 的动作条件分布已经被证明多峰；
3. E2 的距离簇就是可解释的左右策略；
4. 未适配模型在 E4 失败意味着 E4 任务无法学习。

## 下一步

1. 对 E2 成功簇做人类语义复核，判断距离 mode 是否对应可解释的接触策略。
2. 增加显式 mode/prototype 条件作为正对照，测试行为模式是否可控。
3. 为 E4 采集相同初始状态下的配对 demonstration，再进行训练和闭环评测。
4. 使用独立 final environment seeds，补齐真正的泛化比较。
