# 2026-07-27 ACT 末尾样本等权与 VAE 实验结论

## 重要进展

- 完成 A1-ObsEqual 20k 训练和 Formal Clean Closed-loop 评测，成功率由 A1 的
  15% 提高到 45%。
- 完成 A1-VAE 20k 训练和 Formal Clean Closed-loop 评测，成功率达到 95%。
- A1-ObsEqual 的 Action Jerk 比 A1 降低 14.1%，结果支持末尾 observation 总训练
  权重过低的猜想。
- A1-VAE 的 Action Jerk 比 A1 降低 26.9%，夹爪命令切换降低 23.0%，是当前 A1
  系列中表现最好的配置。
- 两组实验均使用相同任务、数据、训练步数、seed、执行 horizon 和 20 个初始状态，
  因此可作为受控对比；但当前结论仍只覆盖单任务、单训练 seed。

## 实验问题

本轮验证两个猜想：

1. 原始 ACT 的 padding loss 归一化是否使 episode 末尾 observation 获得更小的总监督
   权重，从而削弱接近篮子时的释放及释放后保持行为？
2. 在相同数据规模下，打开标准 ACT VAE 是否能更好地建模相似 observation 对应的多种
   合理 future action chunk，并改善闭环表现？

这两个实验承接 [[BestPractice/2026-07-25-ACT动作差分损失与公平评测|ACT 动作差分损失与公平评测]]
中的 A1/A2 对比，但本轮不修改动作差分损失。

## 方法

### A1-ObsEqual：每个 observation 等权

原始 A1 将 padding 位置清零后，仍在固定 `[batch, 20, action_dim]` 张量上执行 mean。
越接近 episode 末尾，一个 observation 拥有的有效 future action 越少，因此它对整个
batch loss 的贡献越低。

A1-ObsEqual 改为：

1. 对每个 observation 的有效 future action 求平均；
2. 再对 batch 内 observation 求平均。

这样，一个只剩 1 个有效 action 的末尾 observation，与拥有完整 20 步 action chunk
的 observation 具有相同总权重；但 observation 内每个 action 的权重会随有效 horizon
长度归一化。

### A1-VAE：恢复标准 ACT CVAE

A1-VAE 保持原始 ACT loss 和固定 horizon 归一化，仅打开：

```text
use_vae=true
latent_dim=32
kl_weight=10.0
```

训练时，CVAE encoder 根据 observation 和目标 action chunk 建模 latent posterior；
推理时使用先验 latent。实验目的不是证明 VAE 普遍优于确定性 ACT，而是验证它是否改善
当前任务中的动作多解性和闭环稳定性。ACT/CVAE 背景可参考
[[Robot/VLA/ALOHA硬件与ACT算法|ALOHA 硬件与 ACT 算法]]。

## 受控实验设置

| 字段 | 配置 |
|---|---|
| Task suite | `libero_object`，task ID 8 |
| Dataset size | 20 demonstrations，3233 frames |
| Observation keys | 两路 256×256 RGB + 8D state |
| Action space | 7D relative EEF action |
| Training action horizon | `chunk_size=20` |
| Closed-loop execution horizon | `n_action_steps=5` |
| Control frequency | 10 Hz |
| Training | 20,000 updates，batch size 8，seed 1000 |
| Closed-loop | 相同 20 个 init states，无扰动，无 Temporal Ensemble |

三组主要差异：

| 配置 | L1 归一化 | VAE |
|---|---|---|
| A1 | 固定 20 步张量 mean | false |
| A1-ObsEqual | 每个 observation 内按有效 action mean | false |
| A1-VAE | 固定 20 步张量 mean | true |

## Formal Clean Closed-loop 结果

| 配置 | Success rate | Action TV | Action Jerk | Mean gripper toggles | Model-query p95 |
|---|---:|---:|---:|---:|---:|
| A1 | 3/20（15%） | 0.02615 | 0.03017 | 14.80 | 20.53 ms |
| A1-ObsEqual | 9/20（45%） | 0.02442 | 0.02590 | 13.50 | 14.06 ms |
| A1-VAE | 19/20（95%） | 0.02307 | 0.02205 | 11.40 | 12.39 ms |

### A1-ObsEqual

相对 A1：

- success rate 增加 30 个百分点；
- Action TV 降低 6.6%；
- Action Jerk 降低 14.1%；
- mean gripper toggles 降低 8.8%。

结果达到预先设定的支持标准：成功率提升至少 10 个百分点，且 Jerk 不恶化。因此，这组
结果支持“末尾 observation 总监督过弱会损害闭环行为”的猜想。

### A1-VAE

相对 A1：

- success rate 增加 80 个百分点；
- Action TV 降低 11.8%；
- Action Jerk 降低 26.9%；
- mean gripper toggles 降低 23.0%。

A1-VAE 只在一个初始化状态失败：rollout 达到 time limit，并伴随较多 gripper command
符号切换。其余 19 个初始化全部成功。

## Offline 结果

A1-ObsEqual 已完成 teacher-forced Offline 评测：

| 指标 | A1 | A1-ObsEqual |
|---|---:|---:|
| First-action MAE | 0.02564 | 0.02488 |
| Gripper MAE | 0.04787 | 0.04537 |
| Delta-action MAE | 0.01374 | 0.01392 |
| Teacher-forced Action Jerk | 0.01349 | 0.01353 |

ObsEqual 的 open-loop 指标与 A1 接近，但闭环成功率明显提高。这再次说明 teacher-forced
逐帧误差不能代替闭环任务成功率，相关评测语义可参考
[[BestPractice/2026-07-23-ACT离线评测与标定可视化|ACT 离线评测与标定可视化]]。

A1-VAE 尚未生成 Offline 指标，因此目前不能比较其 open-loop action error。

## 当前结论

在本轮受控条件下：

1. **ObsEqual 实验支持原猜想。** 末尾 observation 不应仅因有效 horizon 较短而获得更小
   的总训练权重；修正后成功率从 15% 提高到 45%，动作连续性没有恶化。
2. **VAE 实验提升更明显。** A1-VAE 达到 95% 成功率，并同时降低 TV、Jerk 和夹爪命令
   切换，是当前 A1 系列最好的已测配置。
3. **两组结果回答的是不同问题。** ObsEqual 验证 loss 权重设计；VAE 验证 latent
   action-chunk 建模。不能仅凭当前结果判断两者是否可叠加，需单独训练组合配置。
4. **Closed-loop 是主证据。** Offline MAE 接近并不代表闭环行为接近，尤其无法充分反映
   释放时机、错误累积和停滞后的重复规划。

## 结论边界与下一步

- 当前每个配置只有一个训练 seed，不能写成跨 seed 的稳定结论。
- 当前只验证一个 LIBERO Object 任务，不能外推到其他任务或真实机器人。
- A1-ObsEqual 的失败阶段尚未逐 episode 标注，不能把全部提升严格归因于释放动作。
- `gripper_toggles` 是原始动作命令的符号过零次数，不等同于机械夹爪完整开合次数。
- TV/Jerk 会受到成功 episode 提前结束和失败 episode 长时间振荡的影响。

下一步优先补充：

1. A1-VAE Offline 评测；
2. 多训练 seed 重复；
3. ObsEqual + VAE 的组合实验；
4. 按失败阶段标注抓取、搬运、释放和释放后保持。
